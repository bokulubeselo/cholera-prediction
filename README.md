# Application d'analyse du choléra — PNECHOL-MD

Application Streamlit accompagnant un mémoire de Master 2.

## Contenu
- app.py : interface Streamlit
- requirements.txt : dépendances Python
- resultats_comparaison_modeles_cholera.xlsx : résultats expérimentaux

## Lancement
streamlit run app.py

Cette application présente des résultats de recherche et ne constitue
pas un outil de diagnostic médical.
